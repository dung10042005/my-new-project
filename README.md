- Biết cách sử dụng các lệnh Git để quản lý mã nguồn.
- Thực hành đồng bộ mã nguồn từ máy tính lên GitHub.

## 2. Nội dung thực hành

Em đã tạo Repository có tên `my-new-project` trên GitHub. Tiếp theo, em thực hành tạo file README.md để giới thiệu dự án và tìm hiểu quy trình quản lý mã nguồn bằng Git.

## 3. Ý nghĩa các câu lệnh Git

**Lệnh `git init -b main`:** Khởi tạo Git Repository mới với nhánh chính tên `main`.

**Lệnh `git remote add origin <URL>`:** Liên kết Repository trên máy tính với Repository trên GitHub.

**Lệnh `git remote -v`:** Kiểm tra địa chỉ Repository từ xa đã được cấu hình.

**Lệnh `git add README.md`:** Đưa file README.md vào vùng Staging để chuẩn bị commit.

**Lệnh `git commit -m "Add README.md file"`:** Lưu các thay đổi đã được đưa vào Staging thành một commit.

**Lệnh `git push -u origin main`:** Đẩy các commit từ máy tính lên GitHub và thiết lập nhánh theo dõi.
